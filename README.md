# Game Jam Starter

This project is structured for a small Godot team using GitHub and Anchorpoint.

## Asset lanes

- `assets/source/` — editable artist-owned files. Put Aseprite, layered art, raw audio, and fonts here.
- `assets/derived/` — optional committed exports such as final sprite sheets or audio conversions. Do not edit these by hand.
- `assets/third_party/` — downloaded packs and their licences. Keep each pack in its own named folder.
- `resources/` — Godot-owned data: `.tres`, `.res`, themes, and gameplay configuration.
- `actors/` — final editable actor scenes generated by Actor Pipeline. One actor per folder.

See `docs/asset_workflow.md` for the exact placement and collaboration rules.

## Game code

- `scenes/gameplay/` and `scenes/ui/` — game scenes
- `scripts/gameplay/` and `scripts/ui/` — game code
- `scenes/demo/`, `scripts/demo/`, and `tests/` — disposable experiments and tests
- `addons/` — editor addons and third-party plugins; game-specific scenes do not go here
